# Ops On Auto - Business Automation Platform

Transform your business operations with intelligent automation solutions that eliminate repetitive tasks and streamline workflows.

## 🚀 Features

- **Workflow Automation** - Automate repetitive business processes
- **CRM Integration** - Seamless customer relationship management
- **Agentic AI** - Intelligent automation with AI agents
- **Voice AI** - Voice-powered business solutions
- **Industry Solutions** - Tailored automation for specific industries
- **Comprehensive Analytics** - Track and optimize your automated workflows

## 🛠 Technology Stack

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS + shadcn-ui
- **Routing**: React Router DOM
- **State Management**: TanStack Query
- **SEO**: React Snap for static generation

## 📦 Installation & Development

### Prerequisites
- Node.js (version 18 or higher)
- npm or yarn package manager

### Setup

```bash
# Clone the repository
git clone https://github.com/Ignorantbird/Ops-On-Auto.git

# Navigate to project directory
cd Ops-On-Auto

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:8080`

## 🚀 Build & Deployment

```bash
# Build for production
npm run build

# Build with SEO pre-rendering
npm run build && npm run postbuild

# Preview production build
npm run preview
```
